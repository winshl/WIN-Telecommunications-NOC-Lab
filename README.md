# WIN-Telecommunications-NOC-Lab
ENTERPRISE NETWORK OPERATIONS &amp; MONITORING LAB

Project Overview

This project demonstrates a simulated enterprise Network Operations Center (NOC) environment built using Proxmox VE and free/open-source infrastructure monitoring and networking technologies.

The objective is to simulate the daily responsibilities of a Network Operations Center Engineer, including infrastructure monitoring, network troubleshooting, incident management, routing diagnostics, performance analysis, and operational documentation.

# Technologies

Proxmox VE

Ubuntu Server

Debian Linux

Zabbix

Grafana

LibreNMS

FRRouting (OSPF and BGP)

Wireshark

SNMP

rsyslog

GLPI

Bash and Python

# Project Objectives

Monitor network and server availability.

Configure and troubleshoot routing protocols.

Detect network anomalies and infrastructure failures.

Investigate latency, packet loss and bandwidth utilization.

Manage incidents and escalation procedures.

Centralize infrastructure logs.

Develop operational procedures and technical documentation.

# Practical Demonstrations

The lab includes simulated router failures, WAN connectivity interruptions, routing adjacency problems, DNS and DHCP outages, network congestion, server failures, and monitoring alerts.

# Documentation

Each project contains architecture diagrams, implementation instructions, configuration examples, troubleshooting evidence and incident reports.

Environment: Personal educational lab. All network failures and troubleshooting exercises are performed in an isolated virtual environment.
